# Synthetic EOI training specimen

**FICTIONAL TRAINING DATA — not a real tender, proposal, price, credential or submission.**

This package demonstrates how an amendment can be traced through a mandatory requirement, its response, and the supporting evidence record. Every organisation, clause, role, date, status and scenario is invented. The validator input includes simulated positive approval and signature states so the structural checker can exercise its valid path; those records are test data, not real sign-offs or authority. “Uganda” appears only as the requested fictional setting; this package makes no claim about Ugandan procurement law or practice.

The response shows a method and an evidence gap. It does not claim delivery experience, identify a real supplier, or set a commercial amount. Do not submit or adapt it as an actual bid without a complete, authorised source pack and professional review.

Files are grouped by purpose. `validator-input.json` is the structural validator input; the prose files and `evidence-register.csv` are the corresponding human-readable specimen and evidence map. `review.html` is a self-contained presentation of the example.
