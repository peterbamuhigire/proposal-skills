# Synthetic EOI training specimen

**FICTIONAL TRAINING DATA — not a real tender, proposal, price, credential or submission.**

This package demonstrates how an amendment can be traced through a mandatory requirement, its response, and the supporting evidence record. Every organisation, clause, role, date and scenario is invented. “Uganda” appears only as the requested fictional setting; this package makes no claim about Ugandan procurement law or practice.

The response shows a method and an evidence gap. It does not claim delivery experience, identify a real supplier, or set a commercial amount. Do not submit or adapt it as an actual bid without a complete, authorised source pack and professional review.

Files are grouped by purpose. `validator-input.json` is the structural validator input; the prose files are the corresponding human-readable specimen. `review.html` is a self-contained presentation of the example.
