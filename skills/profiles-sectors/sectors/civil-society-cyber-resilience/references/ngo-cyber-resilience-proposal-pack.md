# NGO Cyber-Resilience Proposal Pack

[Parent skill](../SKILL.md)

This reference is a self-contained synthesis prepared from Stéphane Duguin,
*Cybersecurity for NGOs: Attack Prevention and Threat Response*.

## Minimum work packages

| Package | Demonstrable result |
|---|---|
| Governance and empowerment | Board owner, incident route, mission priorities, residual-risk decision |
| Capacity and enablement | Training, budget, trusted technical support, shared-protection route |
| Identify | Asset, data, identity, domain, exposure, and affected-person map |
| Protect | MFA, least privilege, patching, secure administration, backup, and privacy controls |
| Detect | Useful authentication, privilege, endpoint, and suspicious-message signals |
| Respond and recover | Containment, evidence preservation, trusted communication, staged restore, integrity checks |

## Proposal measures

Use measures that show changed capability: control operation rate, time to report,
time to contain, tested restore result, privileged-access review completion,
correction quality, and staff or partner exercise findings. Do not report a
training attendance count as proof that the organisation can recover.
