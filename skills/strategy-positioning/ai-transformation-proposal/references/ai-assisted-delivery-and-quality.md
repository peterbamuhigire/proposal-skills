# AI-Assisted Delivery and Quality

[Parent skill](../SKILL.md)

This reference is a self-contained synthesis prepared from Alexio Cassani,
*Code Revealed*, and Stephanie Diamond, *Claude For Dummies*.

## Proposal method

Match the AI interaction mode to consequence and reversibility: exploration for
disposable discovery, supervised assistance for bounded delivery, and
agent-supervised work only with an explicit plan, permissions, checkpoints,
logs, human approval, and rollback. Name what remains human-owned.

## Evidence to promise

Include the execution record, review gates, test and security evidence, cost and
latency measures, failed-path handling, data boundaries, and handoff owner. A
proposal may promise a controlled learning cycle; it must not promise that AI
output is correct merely because a model generated it.
