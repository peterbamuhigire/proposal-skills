The fixture supplies no current-state system inventory, data schema, hosting decision, security specification, transaction volume, availability target or integration list. Those are explicit clarifications, not guessed facts.

**Method and controls.** The fictional supplier proposes a gated configuration and deployment: confirm requirements and data ownership; map fields and roles; configure a test environment; execute a documented migration rehearsal on synthetic data; run user acceptance and access-control checks; train nominated administrators; cut over only after client acceptance; and hand over operating notes and issue log. **Scope boundaries.** Production hosting, integrations, data cleansing, data-protection legal review, custom software development, disaster recovery service levels and long-term licensing terms remain subject to the actual BDS/ToR and bidder evidence. No production change or data transfer is authorized by this sample.

The fixture still omits real addresses, originals/signatures, mandatory forms and price; package is **blocked** and not for submission.
